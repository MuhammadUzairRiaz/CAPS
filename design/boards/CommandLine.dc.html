caps 0.1.0 — Chain Assembly and Packing Suite
 
usage: caps <command> [options]
 
build make monomers, chains, crystals, surfaces, blends
type assign a force field and report why each atom got its type
grow grow chains into a periodic cell (Theodorou–Suter, CBMC)
pack pack molecules into regions (no packmol)
relax minimise energy (SD, CG, L-BFGS, FIRE)
md run molecular dynamics
equilibrate run a published protocol (larsen21, pushoff, annealing)
react crosslink with atom-mapped templates
analyze density, RDF, S(q), Rg, C∞, Tg, elastic constants, MSD
export write LAMMPS, GROMACS, PDB, mol2, CIF, xyz …
run run a YAML/JSON recipe
bench regenerate validation Tables 1–12
