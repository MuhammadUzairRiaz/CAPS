Command architecture · top calls down

AdaptersAvalonia GUI · CLI · Python (nanobind) · gRPC daemon
Command busEvery user action is a named command with arguments — recorded, replayable, testable
Undo stackCommands produce inverse deltas; history is editable and saved with the document
Document modelAtoms (SoA), bonds, cell, residues, types, selections, monitors
Engines (C ABI)Chem · Field · Grow · Pack · Relax · Dynamics · Equilibrate · React · Analyze · IO

One action, three front ends

GUIdrag bond C12 → C31
CLIcaps edit bond.add 12 31 --order 1
Pythondoc.bond.add(12, 31, order=1)
All three emit the same bond.add command. Undo reverts it the same way, and the history panel shows it once.
