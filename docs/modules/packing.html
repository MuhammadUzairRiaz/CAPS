Packing

CAPS Pack fills an empty box, or the free space around the current structure, with molecules in regions you define, so that no two atoms of different molecules are closer than the tolerance. Packmol inputs open too.

Open it Top bar›Packing

You start with
Molecules (SMILES, files, curatives, solvents) and optionally a structure to pack around.
You get
A packed periodic cell, ready to type, minimise or export.

Step by step

  1. Choose what to pack into

    An empty box, or Around the current structure — the structure is kept fixed and molecules fill its cell (solvent in a polymer, gas in a pore).

  2. Add the molecules

    Add molecule: from a SMILES, your molecules, rubber curatives and additives, solvents, or a file (pdb, mol2, xyz, data, gro). Set the number of copies of each.

  3. Add regions (optional)

    Add region: a box, a slab between two planes, a sphere or a cylinder, to put molecules where you want them.

  4. Set the objective

    Tolerance d_tol 2.0 Å. Fill to a density… sets the count for you; optionally compress the cell afterwards.

  5. Press Pack

    The report shows convergence and the guarantee: the smallest distance now against the target. Then Export to LAMMPS / GROMACS…, or minimise and run dynamics first.

Open input… reads a Packmol input; Save input… and Copy as Python repeat the same packing later.

The same without the Studio

Every Studio page calls the same core as the caps command and the caps Python package, so a step you clicked can be repeated in a script.

caps pack mixture.inp -o mixture.data   # packmol-style input
import caps

box = caps.pack([("CCO", 50), ("O", 200)], box=30.0, tolerance=2.0)
box.save("mixture.data")
