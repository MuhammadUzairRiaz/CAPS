Semicrystalline stack

Cut a lamella from a polymer crystal of the library and grow the amorphous layer between it and its periodic image from the crystal's own repeat unit: loops, bridges and tails in the fractions you ask for, at the amorphous density, relaxed with the polymer's force field.

Open it Build›Semicrystalline stack

You start with
A crystal from the list (or, on the command line, a CIF of another polymer crystal).
You get
A lamellar cell with the groups crystal and amorphous, its force field assigned, and a report: segment counts and lengths, crystallinity from the chain order parameter, density and order profiles along the stack, stem tilt.

Step by step

  1. Choose the crystal

    Pick it from the list. Its defaults fill in: cells across the chains, lamella and amorphous thickness, segment fractions and amorphous density, and the force field (OPLS-AA 2024 or PCFF, whichever types every atom of that polymer's cell).

  2. Set the layers

    Lamella and amorphous thickness in nm, the fractions of loops, bridges and tails, adjacent or random re-entry. Cells whose c is not normal to ab (PET, nylon 66, PEO) give stems that lean; the report gives the angle.

  3. Press Build stack

    The view colours the crystal and amorphous groups. Report of the open cell reads the same counts from any frame after MD.

  4. Equilibrate on a cluster

    caps semicrystalline --lammps-input writes a minimisation, NVT with the crystal tethered, then NPT with each axis on its own. Because the deck minimises the cell itself, --no-relax skips the relaxation in CAPS, which for a library-size cell (about 14,000 atoms for nylon 6) takes tens of minutes on one thread.

The same without the Studio

Every Studio page calls the same core as the caps command and the caps Python package, so a step you clicked can be repeated in a script.

caps semicrystalline --polymer list
caps semicrystalline --polymer nylon6-alpha -o nylon6.data \
    --lammps-input nylon6.in --no-relax
