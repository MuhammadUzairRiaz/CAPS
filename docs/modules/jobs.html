Analyse & export · module 24

Jobs

Follow every run in one place — on this machine, a workstation over SSH, or a SLURM or PBS cluster — with live progress, logs, provenance and help when something fails.

Open it Top bar›Jobs

You start with
Any run page's Queue button, or New here.
You get
Running and finished jobs, their logs, results and provenance.

Step by step

  1. Add a host (once)

    Settings › Compute & remote › Add host: name, hostname, port, user; scheduler SLURM, PBS or none; partition and remote work directory. Test connection checks it (SSH agent).

  2. Send a run

    On any run page set Run on to this machine or a host and press Queue, or start one here with New (grow, pack, relax, dynamics, equilibrate, react, analyze, parameter sweep).

  3. Follow it

    Filter by state, search by title, kind, structure or host. Each job shows Progress live and its Log; Check now polls a remote job.

  4. Get the result

    Open result or Open in Studio. The Provenance manifest records every step.

  5. When a run fails

    What happened and Suggested recovery explain it; Restart with fix runs again with the fix applied; Copy diagnostics for a bug report.
